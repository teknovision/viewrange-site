# viewrange-site

Public pages for the ViewRange iOS app, served by GitHub Pages at
https://teknovision.github.io/viewrange-site/

- `index.html` – what the app does, Free vs Pro
- `privacy.html` – privacy policy (linked from the app and App Store Connect)
- `support.html` – support and how-to (App Store Connect support URL)
- `style.css` – shared stylesheet; `.nojekyll` disables Jekyll processing

Plain static HTML, no build step. Edit and push to `main`.
